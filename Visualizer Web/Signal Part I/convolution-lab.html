Convolution Lab y = x ∗ h

ดูทีละขั้นว่าคอนโวลูชันคำนวณอย่างไร — พลิก h เลื่อนไปทีละตำแหน่ง คูณกับ x แล้วรวม (หรืออินทิเกรต) เป็นเอาต์พุต ใช้โจทย์จากสไลด์ หรือเขียนสัญญาณเองเป็นสูตรพร้อมเงื่อนไขก็ได้ ลากบนกราฟเพื่อเลื่อน

x[n]อินพุต

h[n]impulse resp.

วิธีเขียนสูตรและเงื่อนไข
  • ตัวแปร n · ค่าคงที่ pi, e
  • + - * / ^ และคูณติดกันได้ เช่น 2n, (1/2)^n, 0.8^n cos(pi n/4)
  • ฟังก์ชัน u[n], delta[n] (หรือ δ[n]), exp(), sin(), cos(), sqrt(), |n|
  • แต่ละแถวคือ “สูตร เมื่อ a ≤ n ≤ b” (จำนวนเต็ม รวมไม่เกิน 20 จุด) นอกทุกเงื่อนไข = 0 ถ้าช่วงทับกัน ใช้แถวบนก่อน

ทำไมสูตรเป็นแบบนี้

  1. แยก x[n] เป็นอิมพัลส์ที่เลื่อนแล้วคูณน้ำหนัก: x[n] = Σ x[k] δ[n − k]
  2. ระบบ time-invariant: อินพุต δ[n − k] ให้เอาต์พุต h[n − k]
  3. ระบบ linear: รวมผลตอบสนองทุกตัว ได้ y[n] = Σ x[k] h[n − k]
n = 0
  1. พลิกh[k] → h[−k]
  2. เลื่อนh[−k] → h[n − k]
  3. คูณx[k] · h[n − k]
  4. รวมΣk → y[n]

วิธีตาราง (Tabular method)

แต่ละแถวคือ h ที่กลับด้านแล้ววางใต้ x[k] ให้ h[0] (สีน้ำเงิน) ตรงกับคอลัมน์ k = n — คูณคอลัมน์ที่ตรงกัน (ช่องสีม่วง) แล้วบวก คลิกแถวเพื่อกระโดดไปที่ n นั้น

x(t)สัญญาณอินพุต

h(t)impulse response

วิธีเขียนสูตรและเงื่อนไข
  • เลือก “✎ เขียนเอง” ในเมนูรูปแบบ แล้วแก้สูตรกับช่วงได้เลย
  • ตัวแปร t · ค่าคงที่ pi, e
  • + - * / ^ และคูณติดกันได้ เช่น 2t, 3e^(-2t), e^-t, t e^-t
  • ฟังก์ชัน exp(), sin(), cos(), sqrt(), |t| หรือ abs(), u(t), rect(t), tri(t)
  • แต่ละแถวคือ “สูตร เมื่อ a ≤ t < b” ใส่ inf / -inf หรือ 2pi ได้ นอกทุกเงื่อนไข = 0 ถ้าช่วงทับกัน ใช้แถวบนก่อน

แบ่งช่วงคิดตามค่า t

    จุดเปลี่ยนช่วงคือผลบวกของขอบ (รวมรอยต่อเงื่อนไข) ของ x กับ h — ในแต่ละช่วงเขียนอินทิกรัลเป็นสูตรเดียวได้ ถ้าช่วงที่ซ้อนทับคร่อมรอยต่อ จะแยกเป็นหลายอินทิกรัล

    ขั้นตอนแบบกราฟ (สไลด์ 61)

    1. ตรึงค่า t แล้ววาด x(τ) กับ h(t − τ) บนแกน τ
    2. คูณกันเป็น g(t, τ) = x(τ) h(t − τ)
    3. อินทิเกรตเทียบ τ = พื้นที่ใต้ g — τ หายไป เหลือ y(t)
    t = 0
    1. พลิกh(τ) → h(−τ)
    2. เลื่อนh(−τ) → h(t − τ)
    3. คูณx(τ) · h(t − τ)
    4. อินทิเกรตพื้นที่ → y(t)
