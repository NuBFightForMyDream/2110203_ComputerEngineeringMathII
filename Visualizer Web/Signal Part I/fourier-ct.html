01 ทำไมทุกอย่างเริ่มที่ ejωt — eigenfunction ของระบบ LTI

ป้อน est เข้าระบบ LTI แล้วเอาต์พุตคือ ตัวมันเองคูณค่าคงที่ H(s) — ความถี่ไม่เปลี่ยน เปลี่ยนแค่ ขนาด กับ เฟส เพราะงั้นถ้าเราแตกสัญญาณเป็นผลรวมของ ejωt ได้ เราก็รู้เอาต์พุตของทั้งระบบทันที นี่คือเหตุผลทั้งหมดที่เรียน Fourier

Eigenfunction property

y(t) = ∫∞−∞ h(τ) es(t−τ) dτ = est ∫∞−∞ h(τ) e−sτ dτ = H(s) · est
estอินพุตรูปเอ็กซ์โปเนนเชียลเชิงซ้อน (eigenfunction)
H(s)ค่าคงที่เชิงซ้อน = eigenvalue ของระบบที่ความถี่นั้น
h(τ)impulse response ของระบบ
s = jωเมื่อสนใจเฉพาะความถี่จริง ๆ → H(jω) = frequency response
ความถี่ของเอาต์พุตเท่าเดิมเสมอ — ยิ่ง ω สูง ระบบ RC ยิ่งลดขนาดและหน่วงเฟสมากขึ้น (เป็น lowpass)

02 Fourier series — สัญญาณคาบ = ผลรวมของฮาร์มอนิก

สัญญาณคาบ T ใด ๆ เขียนเป็นผลรวมของ ejkω₀t ที่ความถี่เป็นจำนวนเท่าของ ω₀ = 2π/T ได้ — เลื่อนจำนวนฮาร์มอนิก N แล้วดูผลรวมค่อย ๆ กลายเป็นรูปเดิม

สูตรคู่ของ Fourier series (สมการ 3.12 / 3.13)

x(t) = Σ∞k=−∞ ak ejkω₀t ak = 1T ∫<T> x(t) e−jkω₀t dt
ω₀ความถี่มูลฐาน = 2π/T (rad/s)
kฮาร์มอนิกที่เท่าไหร่ — k = 0 คือ DC
akน้ำหนักเชิงซ้อน: |ak| = แอมพลิจูด, ∠ak = เฟส
<T>อินทิเกรตช่วงไหนก็ได้ที่ยาวหนึ่งคาบ

ถ้า x(t) เป็นจำนวนจริง จะได้ a−k = ak* เสมอ → |ak| สมมาตร และ ∠ak สมมาตรกลับด้าน จึงจับคู่กันเป็นไซน์จริงได้: x(t) = a₀ + 2Σk≥1 |ak| cos(kω₀t + ∠ak)

Gibbs phenomenon: ตรงจุดที่สัญญาณกระโดด ไม่ว่าจะใส่ฮาร์มอนิกเยอะแค่ไหน ยอดแหลมจะเกินไปราว 9% ของขนาดกระโดดเสมอ (มันแค่แคบลงเรื่อย ๆ) — ลองดันสไลเดอร์ N ไปสุดแล้วซูมดูขอบ

03 สูตร ak ทำงานยังไง — ม้วนสัญญาณรอบวงกลมแล้วหาจุดศูนย์ถ่วง

คูณ x(t) ด้วย e−jkω₀t = จับสัญญาณม้วนรอบวงกลมด้วยอัตรา k รอบต่อคาบ แล้วเฉลี่ย (อินทิเกรตแล้วหารด้วย T) = จุดศูนย์ถ่วง ของเส้นที่ม้วนได้ ถ้าสัญญาณมีฮาร์มอนิกที่ k นั้นจริง จุดศูนย์ถ่วงจะเบนออกจากศูนย์กลาง ถ้าไม่มีมันจะกระจายรอบ ๆ ศูนย์แล้วหักล้างกันหมดเป็น 0

  3. ∫T0 ej(k−n)ω₀t dt = {Tk = n0k ≠ nคุณสมบัติ orthogonal: ฮาร์มอนิกคนละตัวคูณกันแล้วอินทิเกรตหนึ่งคาบได้ 0 (3.8)
  4. ∫T0 x(t) e−jnω₀t dt = an Tเหลือรอดแค่พจน์เดียวคือ k = n (3.9)

05 จาก series ไป transform — ยืดคาบ T → ∞

06 คู่ transform ที่ต้องจำ — และหน้าตาของมัน
