Sampling & Filtering Y = X · H

01 Sampling theorem — สุ่มถี่พอ แล้วกู้สัญญาณเดิมกลับได้เป๊ะ

การสุ่ม = คูณสัญญาณด้วยขบวนอิมพัลส์ p(t) คูณในเวลา = convolution ในความถี่ ผลคือสเปกตรัมเดิมถูกคัดลอกไปวางซ้ำ ทุก ๆ ωs ถ้าสำเนาชนกันเมื่อไหร่ = ข้อมูลพัง (aliasing) กู้คืนไม่ได้

แบบจำลองการสุ่มด้วยขบวนอิมพัลส์

xs(t) = x(t) p(t), p(t) = Σ∞n=−∞ δ(t − nT) ⟹ Xs(jω) = 1T Σ∞k=−∞ X(j(ω − kωs))
ωsความถี่สุ่ม = 2π/T
ωBแบนด์วิดท์: X(jω) = 0 เมื่อ |ω| > ωB
2ωBNyquist rate — อัตราสุ่มต่ำสุดที่ยังกู้คืนได้
Tคาบการสุ่ม (sample spacing)

เงื่อนไข: ωs ≥ 2ωB แล้วเอา lowpass ตัดที่ ωs/2 ก็ได้ x(t) เดิมกลับมาทั้งหมด

02 Aliasing — สุ่มช้าไป แล้วเห็นความถี่ผิดตัว

ถ้าสุ่มไม่ทัน จุดที่ได้จะตรงกับคลื่นความถี่ต่ำกว่าอีกเส้นพอดี ตาเรา (และคอมพิวเตอร์) จะเห็นเป็นเส้นเตี้ยนั้นแทน — นี่คือเหตุผลที่ล้อรถในหนังดูหมุนถอยหลัง ลองตั้ง f = 13 Hz, fs = 10 Hz ตามเดโมในสไลด์แล้วดูว่าได้ 3 Hz

ความถี่ที่รับรู้ (perceived frequency)

fp = |f − k fs| โดย k = ปัดเศษของ ffs

03 คิด Nyquist rate — แบบที่ออกสอบ

โจทย์ในสไลด์: เสียงพูดมีสเปกตรัมเกือบเป็นศูนย์เหนือ 5 kHz ต้องสุ่มเท่าไหร่? ใส่ตัวเลขแล้วดูคำตอบทั้งในหน่วย rad/s และระยะห่างจุดสุ่ม

เทียบของจริง: เสียงคุยโทรศัพท์ตัดที่ 3.4 kHz จึงสุ่ม 8 kHz · เพลง CD เก็บถึง 20 kHz จึงสุ่ม 44.1 kHz (เผื่อ transition band ของฟิลเตอร์ด้วย)

04 ตัวกรองในอุดมคติ — กรอง = คูณในโดเมนความถี่

สัญญาณทดสอบมีไซน์ความถี่ต่ำ + ไซน์ความถี่สูง + สัญญาณรบกวน ลองเลือกชนิดตัวกรองแล้วดูว่าอะไรรอด อะไรถูกตัด ทั้งในกราฟสเปกตรัมและในเวลา

หลักการเดียวที่ใช้

y[n] = x[n] ∗ h[n] ⟺ Y(ejω) = X(ejω) · H(ejω)

ตัวกรองอุดมคติ: |H| = 1 ในแถบผ่าน (passband) และ |H| = 0 ในแถบหยุด (stopband) · ของจริงทำแบบนั้นไม่ได้ ต้องมีแถบเปลี่ยนผ่าน (transition band) และริ้วคลื่น δ₁, δ₂ เสมอ

05 Moving average & differencing — ตัวกรองที่เขียนได้ในบรรทัดเดียว

ตัวกรองที่ใช้จริงบ่อยที่สุดสองตัว: เฉลี่ยย้อนหลัง L จุด (lowpass — ใช้ทำเส้นค่าเฉลี่ยราคาหุ้นในสไลด์) และผลต่างของจุดติดกัน (highpass — ใช้เน้นขอบภาพ)

คู่ที่ต้องจำ

y[n] = 1L ΣL−1k=0 x[n−k] → H(ejω) = 1L · sin(ωL/2)sin(ω/2) e−jω(L−1)/2
y[n] = x[n] − x[n−1]2 → H(ejω) = 12(1 − e−jω) = j e−jω/2 sin(ω/2)

อ่านจากสูตร: ตัวเฉลี่ยมี |H| = 1 ที่ ω = 0 และเป็นศูนย์ที่ ω = 2πm/L · ตัวผลต่างเป็นศูนย์ที่ ω = 0 (ตัด DC ทิ้ง) และสูงสุดที่ ω = π

06 วงจร RC — ตัวกรองจริงตัวแรกที่ทุกคนเจอ

สมการวงจร RC dvc/dt + vc = vs แปลงเป็นโดเมนความถี่ได้ H(jω) = 1/(1 + jωRC) — ดูทั้งสามหน้าพร้อมกัน: ผลตอบสนองอิมพัลส์ ขนาด และเฟส

สามหน้าของระบบเดียวกัน (สไลด์ 199)

RC dh(t)dt + h(t) = δ(t) ⟺ H(jω) = 11 + jωRC ⟺ h(t) = 1RC e−t/RC u(t)

ความถี่ตัด (cutoff) อยู่ที่ ω = 1/RC ตรงนั้น |H| = 1/√2 ≈ 0.707 (−3 dB) และเฟส = −π/4 · ถ้าเอาแรงดันคร่อม R แทน จะกลายเป็น highpass ทันที

ยิ่ง RC มาก ตัวกรองยิ่งแคบ (ผ่านแต่ความถี่ต่ำมาก ๆ) และ h(t) ยิ่งยาว — แคบในความถี่ = ยาวในเวลา เหมือนเดิมทุกครั้ง
